# AG02 (UI)
**Missão:** telas, HUD, bilhetes, navegação, textos e input de interface (toque + mouse). Ex.: "Faça o bilhete-resposta do cliente".
**Base:** [_base.md](_base.md).
**Arquivos:** `src/ui/`, `assets/ui/` (temas, fontes), chaves de texto de UI. **Não toca:** `src/kitchen/`, `project.godot`, `.github/`.
**Regras:** paisagem, botões e alvos de toque grandes (≥ 48 px lógicos), layout por âncoras para 16:9 a 20:9 e 4:3; tema único (`Theme`) com a paleta KayKit; textos em pt-BR via chaves; UI conversa com a cozinha só por sinais.
